# WGSL 无损优化：PBB 固定排序和 S-box 交换（2026-11-23）

本轮直接优化生产着色器，同时保留 [CPU 矿工的独立优化报告](../../miner/docs/cpu-2026-11-23.md) 和 [优化前 CUDA 对照](cuda-ab-2026-11-23.md)。没有降低评分阈值、减少评分模型或移植 PBB 的经验门控。

## 最终结果

用户最终要求按时长而非候选数量测速，见下方一分钟表；先前同量数据只用于验证增益能否复现、检查命中集合。

### 每种实跑一分钟

所有正式测量串行，各有不计入的 2 秒预热；达到 60 秒后，停止派发、排空已开始的批次并写完命中。候选量是结果，不是终止参数。相同环境和低命中条件 p550/x4000/d5000 / Base16384，GPU 统一 batch 524287 / packed32，CPU 为 Ryzen 7 5800X 六线程、batch 10000，真实写 CSV。日周值按 T = 10¹²、持续满载折算。

| 后端 | 实际秒数 | 实际完成 | 名/秒 | T/天 | T/周 |
|---|---:|---:|---:|---:|---:|
| CPU 旧版（6 线程） | 60.004 | 117,073,316 | 1,951,106 | 0.17 | 1.18 |
| CPU 优化版（6 线程） | 60.003 | 158,224,568 | 2,636,930 | 0.23 | 1.59 |
| 旧版 WGSL | 60.008 | 3,560,957,304 | 59,341,376 | 5.13 | 35.89 |
| 优化 WGSL | 60.006 | 3,829,916,535 | **63,825,235** | **5.51** | **38.60** |
| CUDA full32 | 60.010 | 4,546,092,577 | **75,755,302** | **6.55** | **45.82** |

- 一分钟内优化 WGSL 比旧 WGSL 快 **7.56%**。三种 GPU 的公共区间 3,560,957,304 个候选中，136 条完整命中逐行一致。[旧 WGSL 计时](../../target/cpu-opt-2026-11-23/timed/wgsl-wgpu-mine-k49jmhbb/measure/timing.json) · [优化 WGSL / CUDA 计时](../benchmarks/wgsl-cuda-60s-baseline.csv)。
- CPU 优化版比旧源码同工具链重建的基线快 **35.15%**；两次正常协作退出，CSV 都保留 55 列，分别写出 2、3 条命中。[CPU 旧版计时](../../target/cpu-opt-2026-11-23/timed/cpu-head-oh7eckk7/measure/timing.json) · [CPU 优化版计时](../../target/cpu-opt-2026-11-23/timed/cpu-combined-e36zbdcn/measure/timing.json)。

一分钟内 CUDA 的 GPU 内核约 7635 万名/秒，优化 WGSL 约 6711 万名/秒，内核吞吐差 **13.8%**；算上批次提交、回读、CPU 复核与 CSV，端到端差 **18.7%**。这既是内核差，又是两个运行时宿主路径的实测差，不能把全数归因于语言。

### 同量正确性与优化对照

三轮各十亿、串行反向交替，三个后端每轮 33 个命中且 CSV SHA-256 一致。旧 WGSL 使用已有发布 CLI；优化 WGSL 和 CUDA 使用同一验证宿主。[三轮原始记录](../../target/cuda-ab/optimized-1123/metrics.csv)

| 后端 | E2E 名/秒（中位） | GPU 内核名/秒（中位） |
|---|---:|---:|
| 旧版 WGSL | 58,706,022 | 61,965,547 |
| 优化 WGSL | **63,483,327** | **66,928,797** |
| CUDA full32 | **76,049,668** | **76,735,213** |

相对旧 WGSL，优化组合在该对照中 **+8.14% E2E、+8.01% 内核**；此时 CUDA 仍比优化 WGSL 快 **19.79% E2E**。

## 保留的两项改动

1. [打包 S-box 交换](../mining.wgsl#L76-L90)：KSA 和技能 PRGA 复用读出的两个打包字，不为每次写入重新加载共享槽。XOR 差量保持其余三个字节不变；两槽在同一字时，第二次写以第一次写后的字为基础。wide 仍走原路径。
2. [HP 固定比较交换网络](../mining.wgsl#L177-L222)：借鉴 PBB 的 compare-exchange 顺序，用固定 min/max 替代变长插入排序。只用排序后中间四项计算 HP，技能读取的 base 顺序不受影响。

本轮主/影子属性均保留全扫描。此前先收 31 项、过属性关后再补齐的试验没有带来提速，未合入正式内核。

## 单变量筛选

RTX 5060 Ti / Vulkan，p550/x4000/d5000，Base16384，packed32，批 524287。每种变体先捕获 65,537 个候选与 CPU 对拍，再交替两轮各 1.3 亿个；每轮完整命中 CSV 相同。筛选数据见 [第一批指标](../../target/wgsl-lab-1123/screen-1/metrics.csv)、[第二批指标](../../target/wgsl-lab-1123/screen-2/metrics.csv)。

| 第一批变体（对全扫描基线） | E2E | GPU 内核 |
|---|---:|---:|
| 固定 HP 网络 | +4.53% | +3.43% |
| 复用打包 S-box 读值 | +4.17% | +3.05% |
| 两者叠加 | +8.79% | +7.67% |
| 原工作区先收 31 项再补齐 | −3.32% | −4.44% |
| 分段 KSA，只在密钥段边界回绕 | −0.72% | −1.63% |
| 一次读一个打包字并解四槽 | +0.89% | −0.34% |
| 不由宿主请求工作组内存清零 | +1.22% | +0.05% |

第二批把打包交换写法简化为 XOR 差量，组合相对该批全扫描基线 +9.39% E2E、+8.18% 内核。仅影子收前 31 项、4 字节算术映射收益在短测里至多相当，不为不到一百分点的差异扩展着色器；无分支哨兵压缩比已选组合慢。PBB 的分段 KSA 在本轮 CPU 有收益，不意味着相同思路在 GPU 也会提速。

## 验证与复现

启用硬件测试后，库 36 项、命令行单元 6 项、集成 6 项全部通过。覆盖 uploaded/generated、wide/packed、32/64/128 工作组、Base64 和 Base16384、u64 边界、尾批以及真实 CPU/GPU CSV 对拍。重新构建前清除了本轮隔离 target 内的 wgpu-mine 包缓存，并核对正常 CLI 与实验宿主哈希不同，避免把实验宿主复用为发布构建。

普通 WGSL 不依赖 CUDA。本机已保存 [优化版 wgpu-mine EXE](../../target/wgsl-lab-1123/wgpu-mine-optimized.exe)，未替换旧发布 EXE。构建或测试也可指定新 target 目录：

~~~powershell
$env:RUSTC_WRAPPER = ''
$env:WGPU_BACKEND = 'vulkan'
cargo build --release --locked -p wgpu-mine --bin wgpu-mine --target-dir target/wgsl-new
cargo test --release --locked -p wgpu-mine --target-dir target/wgsl-new -- --include-ignored --test-threads=1

# 用现有脚本跑优化版（不要覆盖旧结果目录和 CSV）
& ./wgpu-mine/benchmarks/measure-gpu-extreme.ps1 -Binary ./target/wgsl-new/release/wgpu-mine.exe -Output target/wgsl-new/local.csv -OutputDir target/wgsl-new/local-runs
~~~

按时间复测优化 WGSL 和 CUDA：

~~~powershell
& ./wgpu-mine/benchmarks/build-cuda-ab.ps1
& ./target/release/examples/cuda-ab.exe --seconds 60 --rounds 1 --cuda-mode full --out target/cuda-ab/one-minute-new
~~~

计时前两秒预热不计入结果；到点不再派发后续 batch，保留实际完成数和 CSV。运行量不同，只对拍公共 ID 区间。实测优化 WGSL / CUDA 的 [分钟原始指标](../../target/cuda-ab/one-minute-1123/metrics.csv) 保留 3,829,916,535 个公共候选内的 145 条相同完整命中。

旧版 WGSL 和 CPU 两种二进制使用 [定时 CLI 启动器](../benchmarks/timed-mine.py)。启动器在新控制台等待 CSV 表头，按单调时钟计满一分钟，再只向它刚启动的进程所属的独立控制台发 Ctrl-Break。解析协作退出后的实际完成量、CLI E2E 与写盘行数。

~~~powershell
$root = 'target/cpu-opt-2026-11-23'
$env:WGPU_BACKEND = 'vulkan'
py -3 -B -u ./wgpu-mine/benchmarks/timed-mine.py --mode wgsl --binary target/release/wgpu-mine.exe --seconds 60 --warmup-seconds 2 --batch-size 524287 --gpu-input generated --sbox packed --workgroup-size 32
py -3 -B -u ./wgpu-mine/benchmarks/timed-mine.py --binary "$root/bin/head.exe" --seconds 60 --warmup-seconds 2
py -3 -B -u ./wgpu-mine/benchmarks/timed-mine.py --binary "$root/bin/combined.exe" --seconds 60 --warmup-seconds 2
~~~

要复跑同量的三路对照，用 [CUDA 构建脚本](../benchmarks/build-cuda-ab.ps1) 构建当前 example/DLL，然后用 [三路测量脚本](../benchmarks/measure-cuda-ab.ps1) 的 ReferenceExe 指向保存的旧版 WGSL（不能是新构建的 EXE）。旧版使用 CLI；新版 WGSL 与 CUDA 复用同一个 Rust A/B 宿主和 CPU 复核、CSV 路径。单变量筛选的前后 WGSL 共用同一 CLI 宿主。
